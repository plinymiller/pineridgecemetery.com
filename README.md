# pineridgecemetery.com

Pine Ridge Cemetery, Saranac Lake, New York. A community history and story project; not the official site of the Pine Ridge Cemetery Association.

Single static page (`index.html`), served by GitHub Pages at the domain in `CNAME`.

The volunteer sign-up sheet is in the page but switched off. Set `SIGNUPS_ENABLED` to `true` in the script once a form backend is configured.

Site design by [Pliny Miller Design](https://plinymiller.com).
